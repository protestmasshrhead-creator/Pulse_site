# Сборка языковых версий

Русская версия — источник. Остальные языки генерируются из неё.

    src/                  чистые русские страницы (источник сборки)
    dict/<lang>.json      словарь «русская строка → перевод»
    dict/_source_ru.json  индекс строк (номер → русская строка)
    tools/extract.py      извлечение переводимых строк из HTML и из JS
    tools/build.py        генерация страниц: перевод, языковой префикс в ссылках,
                          hreflang/canonical, переключатель на 8 языков
    tools/build_tr.py     сборка словаря из TSV-файлов вида «номер<TAB>перевод»

## Пересобрать всё

    export SP=$(pwd)/_i18n
    for L in ru en de es cs sk ro hu; do python3 _i18n/tools/build.py $L; done

Запускать из корня репозитория. Сборка идемпотентна: всегда читает из `src/`,
поэтому повторный запуск не задваивает canonical и hreflang.

## Добавить язык

1. Перевести строки из `dict/_source_ru.json` в `dict/<lang>.json`.
2. Добавить язык в `LANGS` и `SEL` в `tools/build.py`.
3. Пересобрать все языки — переключатель и hreflang обновятся на всех страницах.

## Важно

- Правки контента вносить в `src/`, затем пересобирать. Прямые правки
  в сгенерированных папках будут потеряны при следующей сборке.
- Юридический раздел (`legal/`) намеренно исключён из сборки.
