# Pulse Call — сайт

## Ветки

**Вся работа идёт сразу в `main`.** Отдельные ветки под задачи не заводим:
коммитим и пушим напрямую в `main`.

## Структура

Сайт статический, без сборщика. Русская версия лежит в корне, остальные
языки — с префиксом: `/en/`, `/de/`, `/es/`, `/cs/`, `/sk/`, `/ro/`, `/hu/`.

Языковые версии **генерируются** из русской — вручную их не редактируют.
Правки контента вносятся в `_i18n/src/`, затем выполняется пересборка:

    export SP=$(pwd)/_i18n
    for L in ru en de es cs sk ro hu; do python3 _i18n/tools/build.py $L; done

Подробности — в `_i18n/README.md`.

Раздел `legal/` ведётся отдельно, см. `legal/README.md`.
